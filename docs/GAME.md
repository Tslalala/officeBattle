# 《职场神话》· 三版本玩法

大模型驱动的办公室文字游戏。主体为 [`game.html`](../game.html)（认真版/娱乐版 + 共享引擎），惊悚版为独立剧本模块 [`horror.js`](../horror.js)（由 game.html 在惊悚模式下委托调用 `Horror.*`）。运行方式：

```
python serve.py          # 默认 http://127.0.0.1:8787/game.html
python serve.py 9000     # 自定义端口
```

## 惊悚版 UI（2026-09-28 改版）

惊悚版使用专属三层布局（与认真/娱乐版的控制台布局区分）：

1. **细状态栏**：地点、天数时间、理智条、当前目标（"查明陈序的下落 · 线索 x/5"）；模型状态缩成角落小圆点，金钱/绩效隐藏。
2. **大场景**：整幅像素背景（`image-rendering: pixelated`），左上角"楼层地图"按钮取代地点按钮排；未验证线索的地点出现青色菱形调查标记；切地点时名称短暂浮现；18:00 后场景进入昏暗（dusk）状态。
3. **对白与行动区**：像素边框对白框（左侧头像/表情，中姓名对白，下选项，底部常驻自由输入"你想说什么，或做什么？"，带"在××行动/对××说话"上下文标签）；快捷入口 调查/等待/手册/证据/离开。

- **头像**：对话时按职业映射使用 `characters-20/` 六表情像素头像（保安老赵←01、前台小虹←02、IT阿伟←03、HR何姐←04、实习生小吴←06、周主管←17、林棠←18、神秘前员工陈序←20）；认真/娱乐版对话头像用 `characters-chibi.png`/`npc-chibi.png` 切图。
- **调查手册**（守则）：每条守则带状态（未验证/已有证据/曾违反）、相关证据入口、违规记录（时间+原因，存于 `S.horror.memo`），页脚显示怪异度。
- **证据页**：五份证据像素卡片（`investigation-items.png` 切图：碎纸便签/信封档案/录像带/U盘；路线图为图标），未获得时显示"？"轮廓与模糊提示，已获得显示在哪里/已确认事实；档案+录像→备份的印证提示。
- **氛围表现层**（跟随理智，`prefers-reduced-motion` 下全部关闭）：理智<80 时钟偶尔跳帧；<60 头像短暂错表情、正文单词闪变（可恢复）；<40 屏幕边缘像素噪点。数值与结局仍由 horror.js 判定。
- **移动端**：状态栏→场景→对白→常驻输入→快捷入口（横滑），无横向滚动，地图/手册/证据抽屉全宽。

```
python serve.py          # 默认 http://127.0.0.1:8787/game.html
python serve.py 9000     # 自定义端口
```

`serve.py` 静态托管本目录，并把 `/v1/*` 反代到内网大模型（`http://10.133.72.161:20133`，Qwen3.8-27B-BF16），绕开浏览器跨域。直接双击 `game.html`（file://）也能玩：会尝试直连大模型，失败则自动落入离线内置剧本模式（每个模式自带事件池、NPC 台词、守则）。

| --- | --- | --- |
| 📈 认真版 · 浮沉记 | 升职加薪、斗倒对手的写实职场 | 情报/盟友系统，集齐可触发隐藏结局「斗倒周主管」；第10天季度考核定结局 |
| 🐲 娱乐版 · 奇幻办公室 | 领导宝可梦对战、打印机成精 | 回合制对战（PPT暴龙/KPI金蝎/404幽灵/退休之影·大老板），大模型逐回合解说；零食可收服 |

## 惊悚版剧本与玩法

入职第一天，林棠递来七条办公室守则。玩家要查明前员工陈序为什么从记录和同事记忆中消失，并在第十天以前逃出楼层。调查顺序可以自由选择，但门禁备份需要人事档案与旧监控录像相互核对；消防楼梯路线还需要录像和备份。全部五份证据到手后，第三天起可在 18:00 第一次下班铃后尝试逃离。

- **守则会生效**：在茶水间、第四工位、监控室、电梯间和卫生间等处有明确选择；随机出现的守则事件也有遵守和违反两种结果。违反会损失理智、提高怪异度。理智归零或怪异度达到上限会提前结局。
- **调查笔记**：右侧操作栏能查看五份证据的进度、理智与违规则次数。新增监控室、档案室、机房、消防楼梯和电梯间；移动不耗时间，完成一次调查推进一个时间槽。
- **自己写行动**：右侧“自己写下行动”支持自然语言。大模型把文字解释为调查、看守则、找人谈话、等待或尝试逃生；实际线索和生死由剧本判定，离线时有关键词解释。点击场景人物后也能选择“直接打字”进行自由对话。
- **逃生**：第一次铃响后按录像、门禁和路线图走消防楼梯，拒绝第二次广播和电梯指引。玩家可以在发现条件后尝试；不足的证据会在出口给出提示。

原 `prototype/pixel.html` 仍是独立的五分钟剧情原型；十天制惊悚版在 `game.html`。大模型可用于人物即兴对白、文字行动理解和每日小结；断线时关键剧情仍可完成。

## 共通玩法

- 一天 6 个时间槽（09:00–16:30，午休摸鱼无危险）+ 下班时段（加班/开溜/顺零食/惊悚版深夜探查）。
- 指定活动全部实现：回消息、刷短视频、打手游、看小说、B站、看电影、摩尔庄园、带薪拉屎（免费不占槽，3次/天，蹲多了有社死事件）、散步、跟同事闲聊、顺零食回家。
- 职场修罗场：对同事（甩锅/抢功/结盟/撕逼）、对上司（汇报/邀功/拍马屁/硬刚）、对下属（使唤/画饼/请奶茶），成功率由绩效、情报、盟友、好感共同决定，欺软怕硬有效但也有反噬。
- 每个时间槽概率触发大模型生成的随机事件（贴合当前状态与最近历史，JSON 结构化输出，解析失败自动降级内置事件）。
- 点击场景 NPC 可闲聊/打听/自由输入对话，大模型按人设与当前关系扮演；打听有几率获得情报。
- 危险度（摸鱼被抓）系统：危险越高越容易被周主管突袭，可狡辩。
- 第 4 天周会事件、第 7 天发薪日、第 10 天考核/终局；localStorage 自动存档，可续玩。

## 大模型接入

- 端点：`http://10.133.72.161:20133/v1/chat/completions`，模型 `Qwen3.8-27B-BF16`，`chat_template_kwargs.enable_thinking=false` 关闭思维链（与用户给的 Python 示例一致）。
- 用途四处：随机事件生成（JSON）、NPC 对话（纯文本人设扮演）、政治行动演播（纯文本）、宝可梦对战解说（JSON）。
- 全部调用带超时与降级：任何失败都不阻塞游戏，仅右上角状态灯变红（离线内置模式）。
